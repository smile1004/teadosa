계통 여유용량 지도 — re100market 분석 & 구현안

re100market.com/intro의 "GRID MAP" 기능을 분석하고, 태양광도사가 이미 보유한 한전 API·카카오맵 연동을 바탕으로 단계적으로 구현할 수 있는 방법을 정리한 검토 문서 + 프로토타입입니다.
(이 페이지는 내부 검토용이며, 하단 프로토타입은 실제 API를 호출하지 않는 가상 데이터 데모입니다.)

🏠 홈 계통연계조회 지자체조례조회

1. re100market.com "GRID MAP" 기능 분석

인코어드테크놀로지스가 운영하는 "신재생 계통 지도"는 전력 공공데이터(전력거래소 EPSIS 등)와 AI 분석을 결합해, 재생에너지 후보지의 계통 접속 가능성과 사업성을 한 곳에서 확인하게 해주는 서비스입니다. 소개 페이지가 내세우는 핵심 지표는 다음과 같습니다.

971개변전소
8,511개배전선로
4,506건누적 사업성 분석
718만+전국 지번 커버리지

"여유용량부터 배전선로까지 한 흐름으로 확인"이라는 카피 아래, 실제 조작 흐름은 3단계로 안내됩니다.

  1. MW 임계값 입력 → 검색 — 사용자가 필요한 여유용량(MW)을 입력하면, 그 값 이상 접속 가능한 변전소만 즉시 필터링됩니다.
  2. 결과 모달에서 변전소 선택 → 지도에서 위치·여유용량 확인 — 번호가 매겨진 색상 핀으로 변전소 위치와 여유용량을 지도 위에서 함께 봅니다.
  3. 배전선로 해제(토글) → 색상별 라인으로 계통 구조 파악 — 변전소에서 뻗어나가는 배전선로를 색상별 라인으로 지도에 덧씌워 계통 구조를 파악합니다.

이 흐름이 성립하려면 아래 데이터/기술 요소가 미리 갖춰져 있어야 합니다.

  • 전국 변전소의 위경도 좌표 마스터 DB (한전 오픈API 응답에는 좌표가 없어 별도 구축 필요)
  • 변전소별 여유용량을 미리 조회해 두는 캐시·배치 갱신 체계 (971개를 매번 사용자 요청 시 실시간 조회하면 응답이 느리고 API 정책에도 부담)
  • 배전선로의 공간정보(GIS 폴리라인) — 별도 데이터셋 확보 필요
  • 지도 위에 마커·라인을 그리고 클릭 상호작용을 처리하는 지도 SDK 연동

3. 단계별 구현 로드맵

Phase 1 · 즉시 적용 — 기존 단건 조회 결과를 지도로 시각화

test1.html의 조회 결과(현재는 표로만 표시)에 조회한 주소 지점 카카오맵 마커 1개를 추가하고, 여유용량 수치에 따라 마커 색상(녹색/주황/빨강)을 다르게 표시합니다. 새 데이터 구축이 필요 없어 가장 빠르게 적용 가능합니다.

Phase 2 · 변전소 마스터 DB 구축 (검증된 방법)

직접 확인 결과, 당초 가정한 "카카오 지오코딩"은 불가능합니다. 변전소명으로 카카오맵을 검색해도 장소 결과가 없고, 공공데이터포털의 "지역별 공급가능 변전소 정보"도 "국가기밀시설인 변전소의 정확한 위치 노출을 막기 위해" 시군구 단위로 비식별화되어 있으며, 한전 자체 "전력공급 여유지도"도 개별 좌표가 아닌 시군구 음영 지도만 제공합니다.

대신 OpenStreetMap(Overpass API)에서 실제 검증된 대안을 확인했습니다. 완주·전주 권역을 power=substation 태그로 조회해보니 전주변전소·남전주변전소·봉동변전소·팔봉변전소 등 실명 변전소가 정확한 위경도와 함께 등록되어 있었습니다. 구축 절차는 다음과 같습니다.

  1. Overpass API(무료, 키 불필요)로 서비스 권역 bounding box 안의 power=substation 노드·way를 조회해 이름+좌표 수집
  2. 수집한 이름을 한전 API 응답의 substNm(변전소명)과 매칭해 "변전소명 ↔ 좌표" 테이블 작성 (표기 차이는 수동 검수)
  3. OSM에 없거나 이름이 비어있는 변전소는 카카오맵/브이월드 위성뷰에서 변전소 특유의 외형(울타리 안 변압기 야드, 송전탑 집결지)을 육안 식별해 좌표를 수동 보완 — 전국이 아니라 실제 시공 권역만 우선 진행
  4. 완성된 매핑 테이블을 Cloudflare D1(또는 KV)에 저장. 이후 Cron Trigger로 야간에 변전소코드별 한전 API를 순차 호출해 여유용량(vol1/vol2/vol3)을 갱신·캐시하고, 사용자 요청은 "최근 갱신된 캐시값 + 갱신 시각"을 조회하는 방식으로 전환

한계: OSM 커버리지가 전국 971개를 다 채우지 못할 수 있어 서비스 권역 기준 사전 조사가 필요하고, 자원봉사자 편집 데이터라 오차·갱신 지연 가능성이 있습니다. ODbL 라이선스에 따라 "© OpenStreetMap contributors" 출처 표기가 필수입니다.

Phase 3 · MW 임계값 지도 검색 (re100market GRID MAP 벤치마킹)

Phase 2의 캐시 DB를 기반으로, 사용자가 MW 임계값을 입력하면 조건을 만족하는 변전소만 지도에 마커로 표시합니다. 마커 클릭 시 변전소명·변압기·배전선로·각 단계 여유용량을 카드로 보여주고, 정확한 값이 필요하면 "지금 바로 정밀 조회" 버튼으로 test1.html의 실시간 단건 조회와 연결합니다. 아래 프로토타입이 이 단계의 UX를 가상 데이터로 미리 보여줍니다.

Phase 4 · 배전선로 오버레이 (선택 확장)

공공데이터포털 또는 한전의 배전선로 공간정보를 확보할 수 있다면 폴리라인으로 렌더링해 배전선로명별 색상 구분을 추가합니다. 데이터 확보 난이도가 높으므로, 확보가 어려우면 이 단계는 생략하고 변전소 단위 정보만으로도 사업성 검토 가치는 충분합니다.

주의사항
· 한전 오픈API 이용약관상 대량/배치 자동 조회가 허용되는 범위인지 Phase 2 착수 전 반드시 재확인이 필요합니다.
· re100market도 하단에 "전력 공공 데이터 · 전력거래소 EPSIS" 출처를 명시합니다. 태양광도사도 지도 페이지 하단에 "데이터 출처: 한국전력 분산형전원 연계정보 오픈API, OpenStreetMap contributors" 표기를 유지해야 하며, OSM은 ODbL 라이선스상 출처 표기가 의무 사항입니다.
· 여유용량은 갱신 시점 기준 참고값이며, 실제 접속 가능 여부는 한전 검토가 필요하다는 기존 안내 문구("이 결과는 선택한 필지의 연결 선로를 확정하지 않습니다")의 톤을 그대로 유지합니다.

4. 프로토타입 (가상 데이터 데모)

아래는 Phase 3 화면의 조작 흐름을 미리 검토하기 위한 가상 데이터 목업입니다. 실제 API 호출은 없으며, 지도도 실제 카카오맵이 아닌 좌표 목업입니다.
