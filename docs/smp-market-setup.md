# SMP 카드 연동

- 서버 비밀 변수: `SMP_API_KEY`. 로컬은 Git에서 제외된 `.dev.vars`, 운영은 기존 Cloudflare Pages 비밀 변수에 등록 후 배포.
- 홈페이지 경로: `/api/market/smp`
- 원본: `https://apis.data.go.kr/B552115/SmpWithForecastDemand/getSmpWithForecastDemand`
- 실응답 필드: `date`, `hour` (01~24), `areaName` (육지/제주), `smp`.
- 한국 날짜 기준 오늘 이하 날짜 중 육지·제주 각각 24시간 값이 갖춰진 최신 동일 거래일을 선택. 미래 거래일, 결측/충돌 자료로 당일 평균을 만들지 않음.
- 최대·최소는 24개 시간별 값의 최대·최소. 평균은 산술평균을 소수 둘째 자리로 반올림. 화면에 `시간별 SMP 24개 단순평균` 표시. 수요 가중평균 또는 실제 발전소 정산단가가 아님.
- SMP 0과 음수는 유효한 가격. 빈값을 0으로 대체하지 않음.
- 당일 자료가 완성되지 않았다면 직전 완성일과 `최근 제공 자료` 표시.
- 최신순 원본 페이지를 최대 3페이지까지만 확인. 1시간 캐시와 동일 인스턴스 동시 호출 합치기 적용.
- 외부 오류 시 최대 7일 범위의 남아 있는 정상 캐시와 `갱신 지연` 표시. 캐시는 영구 저장소가 아니며 제거될 수 있음.
- REC와 동일하게 요청 시 갱신하며 별도 예약 수집은 아직 없음.
- 검증: `node scripts/test-smp-market.mjs` 및 `node scripts/test-rec-market.mjs`.
