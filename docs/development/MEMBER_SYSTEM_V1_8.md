# 태도사 회원 시스템 v1.8

## 작업 내용
- 마이페이지 회원정보 수정 폼 추가
- 로그인 세션을 이용한 본인 정보 수정 API 추가
- 개인회원과 기업회원 수정 항목 분리
- 이메일 중복 검사 및 서버 검증
- 카카오 주소검색 연결
- 아이디, 회원유형, 사업자등록번호, 승인상태 변경 차단

## 주요 파일
- functions/api/auth/profile.js
- common/js/auth.js
- common/js/mypage.js
- mypage/index.html
- mypage/css/style.css

## 테스트
1. 로그인 후 마이페이지에서 회원정보 수정 클릭
2. 연락처 및 주소 수정 후 저장
3. 새로고침 후 변경값 유지 확인
4. 이미 사용 중인 이메일로 변경 시 차단 확인
5. 기업회원의 회사정보 수정 확인
