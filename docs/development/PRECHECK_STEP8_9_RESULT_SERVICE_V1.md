# STEP8~9 결과확인 / 가능서비스 연동

결과확인:
- 내부 result_version 숨김
- 빈 검토항목은 '세부 내용은 추가 확인이 필요합니다.' 표시
- 인쇄 시 Header/Footer/버튼 제외
- 가능서비스 버튼에 현재 request id 전달

가능서비스:
- 동일 request id의 공개 검토결과 API 재사용
- 종합판정/사업지 유형/신청번호 자동 표시
- 토지형에서는 구조검토 항목 제외
- possible/conditional/not_possible에 따라 서비스 상태 문구 변경
- 개별 서비스의 최종 가능 여부를 자동 확정하지 않고 '진행 검토 가능/조건 확인 필요/추가 검토 필요' 수준으로 안내

D1 변경 없음.
