# 태도사 회원 시스템 v1.9

## 작업 범위
마이페이지 비밀번호 변경 기능을 추가했습니다.

## 신규 파일
- `functions/api/auth/password.js`

## 수정 파일
- `common/js/auth.js`
- `common/js/mypage.js`
- `mypage/index.html`
- `mypage/css/style.css`
- 인증 모듈을 사용하는 HTML의 `auth.js` 캐시 버전

## 비밀번호 정책
- 현재 비밀번호 확인 필수
- 새 비밀번호 8~64자
- 영문, 숫자, 특수문자 각각 1개 이상 포함
- 새 비밀번호와 확인값 일치
- 현재 비밀번호 재사용 차단
- bcrypt cost 12로 해시 저장

## 세션 정책
비밀번호 변경에 사용한 현재 세션은 유지합니다. 동일 회원의 다른 세션은 모두 삭제하여 다른 기기와 브라우저의 로그인을 종료합니다.

## D1 변경
테이블 변경 및 별도 SQL 실행은 필요하지 않습니다.

## 배포 후 테스트
1. 현재 비밀번호 오류 확인
2. 새 비밀번호 규칙 오류 확인
3. 확인값 불일치 확인
4. 정상 변경 확인
5. 현재 브라우저 로그인 유지 확인
6. 로그아웃 후 기존 비밀번호 로그인 실패 확인
7. 새 비밀번호 로그인 성공 확인
