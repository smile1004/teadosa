# 사전검토 관리자 검토항목 고정 3개

관리자 검토결과 작성:
1. 조례 검토
2. 한전 계통연계 검토
3. 현장조건 검토

각 항목:
- 상태 선택
- 상세 검토내용 입력

저장:
- 기존 result_data.items JSON 구조 유지
- id: ordinance / grid / site
- DB 스키마 변경 없음

고객 안내사항:
- 기존 사전검토 결과보고서 하단 '중요 안내사항' 중
  1) 인허가 및 지자체 조례 검토
  2) 한국전력 계통연계 검토
  내용을 기본값으로 자동 입력
- 브라우저뿐 아니라 저장 API에서도 기본값을 보장
