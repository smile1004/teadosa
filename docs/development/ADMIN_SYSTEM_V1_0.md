# 태양광도사 Admin System v1.0

## 목표
관리자 기능을 일반 홈페이지와 분리된 운영 화면으로 구성한다.

## URL
- `/admin/` 관리자 대시보드
- `/admin/members/` 회원관리 및 기업회원 승인

## 주요 기능
- 서버 기반 관리자 권한 검증
- 전체/개인/기업/승인대기 회원 수 집계
- 최근 가입 회원 5명 표시
- 회원 검색 및 필터
- 기업회원 승인/승인취소
- 승인취소 시 해당 회원 세션 삭제

## D1
기존 `members.role` 컬럼을 사용하므로 v2.0에서 role 컬럼 생성과 관리자 계정 지정까지 완료했다면 추가 SQL은 필요 없다.

## 배포 후 테스트
1. 관리자 계정 로그인
2. `/admin/` 접속 및 현황 숫자 확인
3. `/admin/members/` 회원검색
4. 승인 대기 기업회원 승인
5. 일반회원의 `/admin/` 접근 차단 확인
