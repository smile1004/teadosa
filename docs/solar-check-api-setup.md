# 태양광 설치 가능성 간편검토 API 연결

샘플 화면은 키가 없어도 `샘플 결과 먼저 보기`로 확인할 수 있습니다. 실제 주소 좌표와 카카오 지도를 표시하려면 Cloudflare Pages의 **Settings → Variables and secrets**에 아래 두 항목을 추가합니다.

| Type | Name | Value |
|---|---|---|
| Secret | `VWORLD_API_KEY` | V-World 인증키 |
| Secret | `KAKAO_REST_API_KEY` | 카카오 REST API 키 |
| Text | `KAKAO_JAVASCRIPT_KEY` | 카카오 JavaScript 키 |

설정 후 새 배포를 실행합니다.

## 카카오 도메인 등록

카카오디벨로퍼스에서 사용 중인 JavaScript 키의 **JavaScript SDK 도메인**에 실제 서비스 주소를 등록합니다.

- `https://teadosa.pages.dev`
- 실제 운영 도메인이 있다면 해당 `https://` 주소도 추가

카카오 JavaScript 키는 지도 표시에 사용하고, REST API 키는 V-World 주소 조회 실패 시 서버에서 자동 대체 조회하는 용도로만 사용합니다. 네이티브 앱 키는 사용하지 않습니다.

## 현재 샘플에서 실제 조회되는 범위

- 다음 우편번호 주소검색
- V-World 주소 좌표 조회
- V-World 장애·검색 실패 시 카카오 REST 주소검색 자동 전환
- 법정동코드와 지번이 확인되는 경우 필지 식별번호(PNU) 표시
- NASA POWER 장기평균 일사량과 월별 예상 발전량 계산

## 리포트 항목별 현재 구현 범위

- 실제 제공: 주소·지번·좌표·PNU·카카오 지도·참고 면적 기반 용량·NASA POWER 예상 발전량
- 추가 데이터 연동 필요: 지목·면적·용도지역·농업진흥구역·산지·토지이용계획
- 공간 분석 개발 필요: 도로·주거·하천·산림·문화재 이격거리, 필지 경계 기반 경사도
- 관리자 검수 필요: 법률·지자체 조례 판정과 시행일
- 관계기관 확인 필요: 한전 변전소·주변압기·배전선로 및 최종 계통연계 가능 여부
- 카카오 지도와 사업지 마커
- 사용자가 입력한 참고 면적을 기준으로 한 예상 설비용량 범위
- 사전검토 신청 페이지 연결

토지면적·지목·용도지역·건축물대장·조례·경사도·한전 계통정보는 현재 확정값처럼 표시하지 않습니다. 해당 데이터 API와 검증 기준을 추가한 다음 단계에서 연결해야 합니다.
