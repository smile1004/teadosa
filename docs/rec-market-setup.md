# REC 현물시장 연동

- Cloudflare Pages 서버 비밀 변수: `REC_API_KEY` (일반 인증키, 인코딩/디코딩 형식 지원)
- 로컬: Git에서 제외된 `.dev.vars`에 동일 변수 등록. 키 변경 후 개발 서버 재시작.
- 메인 조회 경로: `/api/market/rec`
- 원본: 한국전력거래소 `RecMarketInfo2/getRecMarketInfo2`
- 최신 거래일의 `landHgPrc`, `landLwPrc`, `landAvgPrc` 및 제주 대응 항목 사용. 평균을 재계산하지 않음.
- 거래건수 0이면 가격은 `—`, 상태는 `거래 없음`. 육지/제주 통합 종가는 사용하지 않음.
- 기본 목록은 과거부터 정렬되므로 첫 페이지의 전체 건수로 마지막 페이지를 조회하고 최신 거래일 선택.
- 요청 시 캐시가 1시간 이상 경과했으면 갱신. 별도 예약 수집 작업은 아직 없음.
- 동일 실행 인스턴스 동시 요청을 합치고, Cloudflare 엣지 캐시에 정상 응답을 최대 7일 보관. 오류 시 남아 있는 정상 캐시를 `갱신 지연`으로 표시. 캐시는 영구 저장소가 아니며 지역별로 분리되거나 제거될 수 있음.
- 외부 API 키와 원본 오류/요청 URL을 사용자 응답에 포함하지 않음.
- 운영 반영: 기존 Cloudflare Pages 프로젝트에 비밀 변수를 등록한 뒤 이 변경을 배포. 실제 키는 저장소에 커밋하지 않음.
- SMP는 별도 API 연결 전까지 예시 데이터 유지.
