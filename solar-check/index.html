03

입지·규제 확인항목

자동 확정이 아닌, 다음 단계에서 확인해야 할 중요 항목입니다.

  • 확인 필요
    토지이용 및 용도지역

    필지번호와 토지이용계획을 기준으로 개발행위 가능 조건을 확인합니다.

  • 확인 필요
    지자체 이격거리·조례

    도로, 주거지역, 하천 등 관할 지자체의 최신 기준을 확인합니다.

  • 전문 검토
    건축물 구조 또는 부지 현황

    현장사진, 건축물대장, 음영과 구조안전 조건을 담당자가 검토합니다.

  • 기관 확인
    한전 계통연계

    공개자료만으로 최종 연계 가능 여부를 확정할 수 없어 별도 확인이 필요합니다.

04

토지 정보 및 토지이용계획

햇빛길플러스 리포트의 토지 검토 항목을 동일한 구분으로 제공합니다.

조회 가능PNU·주소·관할지역

V-World 또는 카카오 주소 API 결과로 표시합니다.

추가 연동지목·용도지역·면적

토지특성 데이터 API 승인을 받은 후 PNU 기준으로 조회합니다.

추가 연동농업진흥구역·산지 여부

농지·산지 공간정보 또는 공식 확인서와 교차 확인이 필요합니다.

추가 연동용도지구·용도구역·접함정보

토지이용계획 데이터 연동 후 출처와 기준일을 함께 표시합니다.

05

법률 및 조례 검토

신재생에너지법·전기사업법·국토계획법·지자체 이격거리 조례 순으로 확인합니다.

  • 신재생에너지법기본 안내

    태양광 발전설비의 법적 분류를 안내하되 사업 가능 판정으로 사용하지 않습니다.

  • 전기사업법용도 확인

    사업용·자가소비용과 예상 용량에 따라 허가 또는 신고 절차를 구분합니다.

  • 국토계획법용도지역 확인

    개발행위허가 대상과 제한은 토지이용계획 및 현장조건 확인 후 판단합니다.

  • 이격거리 조례담당자 검토

    관할 지자체의 최신 조례 원문·시행일·예외대상을 확인한 후 판정합니다.

06

이격거리 실측

도로·주거밀집·하천·산림경계·문화재까지의 거리를 검토합니다.

현재 자동 실측 미제공

정확한 사업지 경계와 공식 공간정보 레이어가 필요합니다. 다음 단계에서 필지 경계 좌표를 확보한 뒤 각 시설과의 최단거리를 계산하고, 지자체 조례 기준과 비교하도록 구현합니다.

07

경사도 분석

최대·평균 경사도, 경사 방향, 중심 표고를 확인하는 항목입니다.

지형자료 연동 필요

주소 중심점만으로는 실제 필지 경사도를 대표할 수 없습니다. 필지 경계와 DEM 자료를 결합해 여러 지점을 표본 추출한 후 계산해야 합니다.

08

계통 연계

변전소·주변압기·배전선로의 접속용량과 여유용량을 확인하는 항목입니다.

한전 정식 확인 필요

주소만으로 실제 배전선로를 확정할 수 없고 공개 여유용량도 최종 연계 가능성을 보장하지 않습니다. 담당 사업소 또는 한전 계통연계 검토 결과로 확정합니다.

09

예상 발전량

위치별 일사량과 예상 설비용량을 이용한 참고 계산입니다.
